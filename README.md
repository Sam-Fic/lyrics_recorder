# 歌词分段录音工具（Lyrics Recorder）

为 DiffSinger 声库采集而设计的小工具：把一整首歌的歌词按换行拆成句子，**每两行歌词为一个录音单位**，选中单位后点击录音，产出**同名的 `.wav` 音频与 `.txt` 歌词文本**。

默认录音参数：**48kHz / 24bit / 单声道**（可在界面中修改）。

## 功能

- 歌词输入：粘贴文本，或从 `.txt` 文件加载
- 按换行拆句、过滤空行，每两行为一个单位（奇数行时最后一行单独成单位）
- 单位列表点选，点击「开始录音」→ 点击「停止并保存」
- 每个单位产出同名一对文件：`001.wav` + `001.txt`（UTF-8 歌词原文）
- 可选输入设备：下拉框列出系统所有输入设备，可切换麦克风/声卡；点击「刷新设备」重新枚举（无 PortAudio 时仅保留「默认（系统）」）
- 可选采样率（44100/48000/32000/24000/22050 Hz）、位深（16/24/32 bit）、声道（1/2）
- 输出目录可自由选择（默认 `./recordings`）
- 无声卡自检模式 `--selftest`

## 使用方法

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

Linux 用户还需安装系统图形库与音频库（仅桌面 GUI 录音需要）：

```bash
sudo apt install python3-tk libportaudio2
```

### 2. 启动（桌面 GUI）

```bash
python lyrics_recorder.py
```

### 3. 启动 WebUI（手机麦克风录音，无需桌面麦克风）

```bash
python lyrics_recorder.py --web --https
# 可选：--host 0.0.0.0  --port 8000  --outdir ./recordings
#        --cert 证书路径 --key 私钥路径（默认自动生成自签名证书到脚本目录）
```

启动后控制台会打印两个地址：

- 本机访问：`http://localhost:8000`（localhost 视为安全上下文，HTTP 即可用麦克风）
- 手机访问：`https://<本机局域网IP>:8000`（手机需与本机连同一 Wi-Fi/局域网）

在手机浏览器打开该地址，粘贴/加载歌词 → 解析 → 点单位「录音」（授权麦克风）→「停止并上传」。
音频在手机端编码为标准 WAV（16/24/32bit 可选）后上传，生成与桌面端同名的 `xxx.wav` / `xxx.txt`，
可直接用于后续 TIFA 强制对齐等流程。

> 重要：浏览器只在「安全上下文」下允许访问麦克风（HTTPS 或 localhost）。
> 手机以局域网 **IP** 访问时必须是 **HTTPS**，否则 `navigator.mediaDevices` 为 `undefined`、
> 麦克风不可用且不弹权限框。因此手机访问请务必加 `--https` 参数。
> 自签名证书会触发浏览器安全警告，点「高级 → 继续访问」即可；
> iOS Safari 还需先到「设置 → 通用 → 关于本机 → 证书信任设置」信任该自签名证书。
>
> 注意：部分手机浏览器（尤其 iOS Safari）对 `MediaRecorder` 输出解码支持有限，
> 若上传报「处理失败」，可改用 Chrome/Android 浏览器，或在桌面端完成录音。


### 3. 操作流程

1. 在「歌词」区粘贴一整首歌的歌词（每行一句），或点击「从文件加载」
2. 点击「解析歌词」→ 下方列表出现录音单位（每两行为一个）
3. 在列表中点选一个单位
4. 点击「开始录音」→ 对着麦克风唱/读该单位的两行歌词 → 点击「停止并保存」
5. `001.wav` 与 `001.txt` 会生成在输出目录，对着名单可随时重录覆盖

重复单位录音后，即可把整个目录作为下一步（TIFA 强制对齐等）的输入。

## 无麦自检

```bash
python lyrics_recorder.py --selftest
```

在无图形界面、无麦克风的环境下验证歌词解析与 wav/txt 生成链路是否正常。

## 输出说明

- `001.txt` 内容为该单位两行歌词原文，UTF-8 编码，与 TIFA 等对齐工具要求的同名转写文件格式兼容
- 音频格式为标准 PCM WAV，参数在界面顶部设置
